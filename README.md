# 🚌 Bus Transportation Management System

## 📌 Project Overview

The Bus Transportation Management System is a web-based application developed to simplify bus transportation operations. The system provides separate interfaces for Administrators, Drivers, and Customers, enabling efficient management of bus schedules, trip assignments, ticket bookings, and passenger services.

This project aims to improve transportation management by providing a centralized platform for monitoring bus operations and customer interactions.

## ✨ Features

### 👨‍💼 Admin Module

* Manage bus trips and routes
* Manage driver information
* View reports and analytics
* Send notifications to users
* Monitor transportation activities

### 🚍 Driver Module

* View assigned trips
* Track schedules and routes
* Monitor trip details
* View performance and earnings

### 👤 Customer Module

* User registration and login
* Book bus tickets
* View booked tickets
* Cancel tickets
* Track buses in real-time
* Access support services

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Database Management System (DBMS)
